#### 步骤 1：从 reference PDF 重新提取图片

```python
import fitz  # PyMuPDF

pdf_path = "reference/投标文件【汉西水厂低压】.pdf"
doc = fitz.open(pdf_path)
images_dir = Path("data/images")
images_dir.mkdir(exist_ok=True)

for page_num in range(len(doc)):
    page = doc.load_page(page_num)
    image_list = page.get_images(full=True)
    
    for img_index, img in enumerate(image_list, 1):
        xref = img[0]
        base_image = doc.extract_image(xref)
        image_bytes = base_image["image"]
        image_ext = base_image["ext"]
        
        # 保存图片
        image_filename = f"page{page_num+1:03d}_img{img_index:02d}.{image_ext}"
        image_path = images_dir / image_filename
        with open(image_path, "wb") as f:
            f.write(image_bytes)
```

def _add_tech_solution(self, doc: Document, tender_info: Dict, matched_data: Dict):
    """添加技术方案"""
    p = doc.add_paragraph()
    run = p.add_run("第6章 技术方案")
    run.bold = True
    run.font.size = Pt(16)
    run.font.name = "黑体"
    
    doc.add_paragraph()

    products = matched_data.get("products", [])
    images_dir = self.templates_dir.parent / "data" / "images" / "products"
    
    for i, product in enumerate(products[:10], 1):  # 最多10个产品
        # 显示产品名称和描述
        p = doc.add_paragraph()
        run = p.add_run(f"{i}. {product.get('name', '未知产品')}")
        run.bold = True
        
        doc.add_paragraph(product.get('description', ''))
        
        # 插入产品图片（如果存在）
        product_images = list(images_dir.glob(f"*{product.get('name', '')}*"))
        if product_images:
            img_path = product_images[0]
            doc.add_picture(str(img_path), width=Inches(4.5))
            doc.add_paragraph()

### 方案 2：直接使用证书 PDF（当前已实现）

#### 当前实现

系统已经实现了证书 PDF 转图片的功能，可以：

1. **自动转换证书 PDF 为图片**
   - 使用 pdf2image 库
   - 只转换第一页
   - 图片分辨率：200dpi
   - 图片宽度：5.5 英寸

2. **在投标文件中插入证书图片**
   - 第3章：企业资质
   - 3.1 体系认证证书（质量、环境、职业健康、能源）
   - 3.5 其他证书（型式试验报告、检验报告、专利、软件著作权等）

#### 优点

- 打印出来直接可以看到证书图片
- 客户不需要任何操作
- 投标文件看起来更专业

#### 缺点

- 需要安装额外库（pdf2image + Pillow + Ghostscript）
- 文件会大一些
- 生成速度较慢（需要转换图片）
