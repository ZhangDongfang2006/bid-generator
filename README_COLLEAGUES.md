# 投标文件生成系统 - 同事使用说明

## 系统介绍

投标文件生成系统是一个基于 AI 的智能工具，可以：
1. 自动解析招标文件（PDF 格式）
2. 自动匹配公司资质和项目案例
3. 智能生成完整的投标文件（包括技术标和商务标）
4. 支持证书图片显示
5. 自动生成设备说明一览表和公司通用内容

## 详细使用说明

### 1. 准备工作

#### 1.1 确保文件结构正确
```
bid-generator/
├── app.py                    # 主应用程序
├── generator.py              # 文件生成器
├── company_content.py         # 公司通用内容
├── add_chapter_numbers.py     # 章节编号
├── cleanup_output.py         # 清理脚本
├── database.py               # 公司数据库
├── parser.py                 # PDF 解析器
├── data/
│   ├── company_info.json     # 公司信息
│   ├── products.json        # 产品数据
│   ├── equipment_specs.json # 设备规格
│   ├── qualifications.json   # 资质数据
│   └── cases.json           # 案例数据
├── output/                   # 生成的文件
│   └── archive/             # 归档文件
└── templates/                # 模板文件
```

#### 1.2 准备招标文件
- 格式：PDF
- 文件大小：建议小于 50MB
- 文件内容：包含完整的招标信息和技术规范

#### 1.3 准备公司文件
- 资质证书（PDF 格式）：上传到 `data/certificates/`
- 项目案例（PDF/图片）：上传到 `data/cases/`
- 产品数据（可选）：可以修改 `data/products.json`

## 使用流程

### 完整流程（推荐）

#### 步骤 1：启动应用
```bash
cd /path/to/bid-generator
./start_app.sh
```

#### 步骤 2：上传文件

在浏览器中（访问 `http://localhost:8501`）：

1. **上传招标文件**
   - 点击"📤 上传招标文件"
   - 选择 PDF 文件
   - 等待 AI 解析完成
   - 查看解析结果和置信度

2. **上传公司资质**
   - 点击"📄 上传公司资质"
   - 选择资质证书 PDF 文件
   - 支持多文件上传
   - 可以删除不需要的文件

3. **上传项目案例**
   - 点击"📂 上传项目案例"
   - 选择项目案例 PDF 或图片文件
   - 支持多文件上传
   - 可以删除不需要的文件

#### 步骤 3：填写项目信息
- **项目名称**：输入招标文件中的项目名称
- **项目编号**：输入招标文件中的项目编号
- **项目金额**：输入项目总金额（可选）
- **投标金额**：输入投标金额（可选）
- **项目全称**：自动生成，可以修改
- **招标人**：输入招标单位名称

#### 步骤 4：选择公司资质和案例

系统会自动匹配：
- **资质证书**：根据项目需求自动选择
- **项目案例**：根据项目类型和规模自动选择
- **匹配度**：显示匹配原因和置信度

#### 步骤 5：配置生成选项

- **显示证书图片**：勾选后，生成的文件中会显示证书图片
- **技术标和商务标分开生成**：勾选后，生成两个独立文件

#### 步骤 6：生成投标文件

点击"🚀 生成投标文件"按钮，等待文件生成完成。

#### 步骤 7：下载文件

- 点击"⬇️ 下载"按钮下载生成的文件
- 文件会按时间排序，最新的在前

## 高级功能

### 1. 文件清理
- **清理旧文件**：点击"🧹 清理旧文件"按钮
- **查看文件统计**：点击"📊 查看文件统计"按钮
- **清理规则**：
  - 只清理投标文件（`.docx` 格式）
  - 保留最新 10 份文件
  - 其他文件移动到 `output/archive/` 目录

### 2. AI 解析结果查看
- **解析置信度**：系统显示 AI 对文件解析的可信程度
  - 高：系统非常有信心，解析结果准确
  - 中：系统有一定信心，解析结果基本准确
  - 低：系统信心不足，建议人工核对
- **解析详情**：查看每个字段的解析结果和来源

### 3. 错误处理
- **文件解析失败**：检查文件格式和大小
- **数据库连接失败**：检查 `data/` 目录是否存在
- **生成失败**：查看详细错误信息，检查依赖是否安装

## 常见问题

### Q1: 应用无法启动
**A**:
1. 检查是否已启动 Streamlit
   ```bash
   ps aux | grep streamlit
   ```
2. 如果已启动，杀掉进程
   ```bash
   pkill -f streamlit
   ```
3. 重新启动应用
   ```bash
   ./start_app.sh
   ```

### Q2: 浏览器无法访问 localhost:8501
**A**:
1. 检查应用是否正常启动
   - 查看终端输出
   - 应该看到：`🌐 Streamlit URL: http://0.0.0.0:8501`
2. 检查防火墙设置
   - Windows：允许 Python 通过防火墙
   - Mac/Linux：检查 iptables 或 firewall
3. 尝试使用 127.0.0.1:8501

### Q3: 生成的文件打不开
**A**:
1. 检查文件大小是否正常（应该是 1-5MB）
2. 检查文件是否完整生成
3. 尝试使用 Microsoft Word 或 WPS 打开

### Q4: 证书图片不显示
**A**:
1. 检查是否勾选了"显示证书图片"选项
2. 检查证书文件是否正确上传到 `data/certificates/`
3. 检查是否安装了 Ghostscript 和 pdf2image
4. 重新生成文件

### Q5: 章节编号不正确
**A**:
1. 确保使用最新版本代码
2. 重新生成文件
3. 检查章节编号是否按顺序排列

## 安全和隐私

### 数据安全
- **本地数据**：所有数据都存储在本地 `data/` 目录中
- **云端处理**：如果使用 Streamlit Cloud，文件只在会话期间存在，结束后自动删除
- **不会上传敏感数据**：招标文件、公司数据不会上传到任何服务器

### 访问控制（如果需要）
- 如果使用 Streamlit Cloud，所有链接访问者都可以访问
- 如果使用本地部署，可以通过配置访问控制
- 建议为不同项目创建独立的访问链接
